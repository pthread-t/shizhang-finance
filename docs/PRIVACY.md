# 隐私、安全与无障碍边界

## 数据去向

- 未配置服务器时，账单、索引、OCR 结果和附件只在手机本地。
- 配置私有服务器后，账单与选择同步的附件通过 HTTPS 上传至该服务器。
- 本方案是“服务端可读”，服务器管理员可以读取数据库明文；不是端到端加密。
- 中文 OCR 使用随 APK 捆绑的 ML Kit 模型，输入图片和识别结果在设备上处理。ML Kit SDK 可能向 Google 请求更新、模型或硬件兼容信息，并发送性能和使用统计；这不等于应用整体完全不联网。详见 [ML Kit 隐私说明](https://developers.google.com/ml-kit/terms#privacy)。
- 语音优先使用可用的端侧识别服务；需要系统语音服务时先征求用户同意，再启动识别。是否联网取决于所选系统服务，请求离线模式不代表服务一定离线执行。
- AI 财务助手默认未配置。用户添加 DeepSeek、智谱 GLM 或兼容接口后，问题、账本维度名称和本机计算的聚合结果会由手机直接发送给所选供应商；原子账单、备注、附件和交易 ID 不发送。
- AI API Key 仅存入 Android 加密存储，不进入 SQLCipher 业务表、云同步、日志或 `.billbackup`。AI 会话保存在本机 SQLCipher，可进入用户主动创建的密码加密逻辑备份，但不参与家庭账本同步。

## 无障碍自动记账

该能力默认关闭。服务配置只声明微信 `com.tencent.mm` 与支付宝 `com.eg.android.AlipayGphone`：

- 不执行点击、滑动或任何手势。
- 仅在用户主动启用后读取白名单应用当前窗口。
- 默认生成确认通知，不直接写账。
- 不持久化或记录原始节点文本；日志只保存适配器事件状态。
- 用户可从系统持续状态和应用设置随时关闭。

第三方页面变化会导致识别失效或误识别。若计划通过应用商店分发，发布前必须重新审查最新无障碍政策、数据安全表和显著披露文案。

## 运维要求

- `.env`、keystore、签名密码、JWT 密钥和备份密码不得提交仓库或写入镜像。
- 主机启用全盘加密、最小 SSH 权限、安全更新和受限备份访问。
- 不在诊断日志中加入金额、备注、令牌、恢复码、邀请码或无障碍节点原文。
- 设备撤销、成员变更、同步写入和附件上传应保留审计事件。
